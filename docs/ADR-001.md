# ADR-001: Framework-Free Core Domain

## Status
Accepted

## Context
We need to model order state transitions without binding domain logic directly to frameworks or databases.

## Decision
1. Implement the Domain layer using pure Java objects and records.
2. Invariants are strictly enforced inside domain aggregates.
3. Outbound dependencies (persistence, notification) are inverted using ports.
4. No dependencies on Spring, Hibernate, or external frameworks inside the domain.

## Consequences
- **Positive:** Unit tests run in milliseconds without launching containers or application contexts.
- **Positive:** Infrastructure (database, notifications) can be swapped without touching business logic.
- **Trade-off:** Mapping code is required between domain models and database entities.
